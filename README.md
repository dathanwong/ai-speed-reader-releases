# AI Speed Reader

AI Speed Reader runs on macOS 14 or later. It flashes one word at a time from highlighted text, the message under the pointer, or the clipboard.

## Install

Download the latest [AISpeedReader.dmg](https://github.com/dathanwong/ai-speed-reader-releases/releases/latest/download/AISpeedReader.dmg), open it, and drag AI Speed Reader to Applications. [AISpeedReader-macOS.zip](https://github.com/dathanwong/ai-speed-reader-releases/releases/latest/download/AISpeedReader-macOS.zip) is what the app downloads when it updates. The same page lists Source code (zip) and Source code (tar.gz). Those are GitHub's archive of the releases repository, and they do not include the app.

## First launch

The app shows in the Dock and the menu bar. First launch opens a tour on Speed Calibration. Use Back, Next, Skip tour, or Start Reading. Finishing or skipping opens Dashboard & Stats. Later launches open there too.

Turn on AI Speed Reader in System Settings > Privacy & Security > Accessibility. Until then the menu shows Grant Accessibility Permission…. If an app does not expose its text, screen capture can run and macOS may ask for Screen Recording. Turn Accessibility on again after an update. If macOS blocks the app, allow it in System Settings > Privacy & Security.

## Everyday use

The menu bar shortcut defaults to Option + Space. Read Selection / Hover captures the same way. Hover a message or highlight text, then press it. Read Clipboard Text reads copied text.

The large button says Pause while flashing and Play while paused. Space does the same. Escape closes the panel. Option + Left and Option + Right jump ten words. The panel has -10 and +10 buttons.

Speed starts at 400 words per minute. Settings can set 100 to 1200. Fast is Option + 1 at 700. Technical is Option + 2 at 280. On Speed Calibration, Too Slow, Just Right, and Too Fast change the pace. Record Shortcut… and Reset to Option + Space are in Settings.

Automatic background updates are on. The app checks for a release, downloads AISpeedReader-macOS.zip, and applies it on quit or next launch. Restart to Update is optional. Updates are never required. Check for Updates… still runs with automatic updates off. Check for Updates shows Couldn't reach the update server when the feed cannot be reached. An HTTP 404 there is not the same as having no update.

Stats record counts and speeds, including words read and words per minute. The words you read are not stored.
